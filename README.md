# Vivien portfolio website code

This is the latest portfolio, including the selected original FVA logo, restored certifications, animations, cookie preferences, policies and Tally contact form.

## Open and edit

1. Extract this ZIP.
2. Open `index.html` in your browser to view the page.
3. Open `index.html` in a text editor to edit it. The CSS is inside `<style>` and the JavaScript is inside `<script>`.
4. Keep the `assets` folder beside `index.html` so the logo appears.

No installation or build step is needed. An internet connection is needed to load the Tally form. Cookie persistence depends on the browser and should be checked on the hosted website.

## Included files

- `index.html`: complete page, styles and interactions.
- `assets/fva-monogram.png`: the original selected logo, unchanged.
- `COMPLIANCE_REVIEW.md`: review notes and unresolved items for the website owner.
- `WEBSITE_REQUIREMENTS.md`: your standing website requirements.

The export uses a relative logo path so it works beside the HTML file and under a hosted project folder. The published Site has not been changed by this export.

## Contact form and publishing

The contact form uses your existing Tally form, LZxNbv. Responses and email notifications follow the settings in that Tally account. Add or verify the consent question within Tally and test submission and notification delivery before relying on it.

For static hosting, upload `index.html` and the `assets` folder together. The Markdown files are owner notes and do not need to be published. The private access restriction on the current hosted Site is not included in these static files; access depends on where you host them.

Certification titles are restored from your original page. Certificate documents, dates and verification links were not supplied. See the review notes for other facts and rights that still need confirmation.
